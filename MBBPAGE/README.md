# Método Bebé à Mesa — site estático

Para publicar: extraia este ZIP, envie **o conteúdo da pasta** para a raiz de um repositório GitHub e importe o repositório no Vercel. Use o preset **Other**. O `vercel.json` aponta para `public/`; não é necessário comando de build.

A ligação Hotmart está no CTA do card de preço. O pixel e o script de UTMs da UTMify estão no cabeçalho de `public/index.html`.
